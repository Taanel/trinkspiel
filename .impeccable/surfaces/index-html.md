# Surface: game app (index.html, all screens)

Mode: Operate. Each player's phone is a private controller during a party at night.
Task per screen: know what to do now (join, pick game, read rules, vote/answer, see who drinks).
Constraints: DE/EN/VI with Vietnamese diacritics, one-thumb use, dim room, reduced motion respected.

## Direction contract

THESIS: Every round is a freshly drawn street lottery ticket (vé số); the reveal is the draw. Refuses the category default of dark neon-purple party app with emoji tiles.

OWN-WORLD: Deep night ground #14182E. Tickets are bright printed paper (lemon #F6E27A, pink #F4A7BE, mint #9FE3C9, lilac #B9B4F5, apricot #F7B267) with fine guilloche, a dotted perforation edge, serial-number labels in print blue #2440A8. Ink red #D7263D only for "you drink". Bricolage Grotesque condensed for display and numerals, Be Vietnam Pro for text. Only the active ticket carries guilloche; everything else is quiet night.

STORY: Players see the room as a serial number, pick a game ticket, read 3 steps, play, and watch results roll in like draw digits; the end screen is the xổ số results board ranked by sips.

FIRST VIEWPORT: Lobby on a 390px phone: top row room serial "PHÒNG № KXPT" left, language toggle right; display title; player avatars row with punch holes; Party-Mix as large ticket, four game tickets 2x2 plus cards ticket; rounds segmented control and lemon start button pinned bottom in thumb zone.
